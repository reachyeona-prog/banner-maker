# 출력 JSON 스키마

## 1. 최종 출력 형식

**항상 단일 JSON 코드블록**을 출력합니다. 설명·서론·맺음말 일절 금지.

\`\`\`json
{
  "title": "string",
  "source": "string",
  "cover": { ... },
  "interiorSlot": "E2",
  "interiors": [ { ... }, ... ]
}
\`\`\`

## 2. 전체 스키마

```typescript
type CardNewsSet = {
  title: string;        // 내부 제목 (도구에 입력되진 않음, 식별용)
  source: string;       // 원문 URL/출처 (없으면 빈 문자열 또는 "직접 입력")
  cover: CoverSlide;    // 표지 1장
  interiorSlot?: "E2" | "E4" | "E5" | "E8";  // 내지 레이아웃 (생략 시 E2)
  interiors: InteriorSlide[] | ChecklistSlide[];  // 내지 3~6장
};

type CoverSlide = {
  type: "E1";           // 고정값 — 카드뉴스 표지 슬롯 ID
  pill: string;         // 카테고리 라벨 (1~6자). 예: "NEWS", "트렌드", "매장 운영 TIP"
  main1: string;        // 메인 카피 1줄 (8~14자 권장)
  main2: string;        // 메인 카피 2줄 (8~14자 권장)
};

type InteriorSlide = {
  type: "E2" | "E4" | "E5";  // 내지 슬롯 ID (interiorSlot과 일치)
  main1: string;        // 메인 카피 1줄 (10~16자 권장)
  main2: string;        // 메인 카피 2줄 (10~16자 권장)
  main3?: string;       // 메인 카피 3줄 (선택 — 슬라이드별로 2줄/3줄 자유롭게 섞을 수 있음)
};

// 체크리스트 카드 (E8) — 박스 타이틀 + 체크박스 항목 리스트
type ChecklistSlide = {
  type: "E8";
  title1: string;       // 박스 타이틀 1줄 (6~14자)
  title2?: string;      // 박스 타이틀 2줄 (선택, 6~14자)
  items: ChecklistItem[];   // 항목 3~5개
  titleStyle?: "invert" | "point";  // 생략 시 invert
  card?: boolean;       // 항목 배경 흰 카드 (생략 시 true)
  numbered?: boolean;   // 항목 번호 (생략 시 true)
  startNo?: number;     // 시작 번호 — 생략하면 앞 슬라이드에서 자동으로 이어짐
};

type ChecklistItem = {
  text: string;         // 항목 제목 (15자 내외, 최대 20자)
  desc?: string | string[];  // 설명 (선택). 줄바꿈은 "\n" 또는 배열로
};
```

> 모든 내지 슬롯이 **자동 줄 수 감지**를 지원합니다. main3 비우면 2줄, 채우면 3줄로 렌더. 같은 세트 안에서 슬라이드마다 다르게 써도 OK.

## 2-1. 내지 레이아웃 선택 (`interiorSlot`)

콘텐츠 성격에 맞춰 3종 중 하나 선택:

| 슬롯 | 레이아웃 | 적합한 콘텐츠 |
| --- | --- | --- |
| **E2** (기본) | 메인 카피 상단(중앙) + 인포그래픽/이미지 하단 | 데이터 차트·지도·요약 그래픽 |
| **E4** | 이미지 상단 + 메인 카피 하단(중앙, 아래 앵커) | 사진 중심 + 캡션형 설명 |
| **E5** | 배경 사진 위에 흰 박스(블랙 테두리) 카피 | 강조형 메시지 카드·정리 박스 |
| **E8** | 박스 타이틀 + 체크박스 항목 리스트 | 점검 항목·준비물·단계별 가이드 |

**선택 가이드**:

- 데이터 트렌드 분석 → **E2**
- 사진 중심 + 본문 설명 → **E4**
- 강조 박스로 시선 집중 (요약·결론·CTA) → **E5**
- "~하셨나요?" 형태로 **항목을 나열**하는 콘텐츠 → **E8**

한 카드 뉴스 세트는 **하나의 레이아웃을 일관되게** 사용하세요. (도구가 한 번에 한 슬롯만 처리)

## 2-2. 체크리스트 세트 (`interiorSlot: "E8"`)

점검·준비물·단계 안내처럼 **항목을 나열하는 콘텐츠**는 E8을 씁니다. 카피 구조가 달라 `main1`/`main2` 대신 `title1`/`title2` + `items`를 씁니다.

```json
{
  "type": "E8",
  "title1": "여름 매장 점검",
  "title2": "체크 리스트",
  "items": [
    { "text": "에어컨 필터 청소하셨나요?", "desc": "2주에 한 번은 청소해야\n전기세가 덜 나와요" },
    { "text": "냉장고 온도 확인하셨나요?" }
  ]
}
```

**규칙**

- `title1`은 필수, `title2`는 선택. 각 **6~14자** (길면 도구가 자동으로 줄여 한 줄에 맞춤).
- 같은 세트의 모든 슬라이드는 **같은 타이틀**을 쓰는 게 자연스럽습니다 (연속된 장으로 읽힘).
- `items`는 **슬라이드당 3~5개**(4개 권장). 6개가 넘으면 글자가 작아져 가독성이 떨어집니다.
- `items[].text`는 **15자 내외(최대 20자)**. `~하셨나요?` `~있나요?` 같은 확인형 질문체가 잘 맞습니다.
- `items[].desc`는 선택. 한 항목당 **1~2줄, 줄당 20자 내외**. 줄바꿈은 `"\n"` 또는 `["1줄","2줄"]`.
- 항목이 많아 여러 장으로 나눌 때 **`startNo`는 생략하세요** — 도구가 앞 슬라이드에서 이어지는 번호(1~5 → 6~10)를 자동으로 매깁니다.
- `titleStyle`·`card`·`numbered`는 디자인 옵션이라 **보통 생략**합니다. 배경이 어둡거나 항목을 배경 위에 바로 올리고 싶을 때만 지정.
- 타이틀 양옆 장식 이미지는 JSON으로 못 넣습니다 (도구에서 직접 업로드).

## 3. 필드별 규칙

### `title`
- 카드 뉴스 세트의 내부 제목. **사용자에게만 보이고 도구엔 안 들어감**.
- 원문 핵심을 한 줄로 요약. 8~20자.
- 예: "벚꽃 상권 매출 분석", "고유가 피해지원금 가이드"

### `source`

- 원문 출처 — URL이 본문에 같이 적혀 있으면 그 값, 아니면 `"직접 입력"` 또는 빈 문자열.
- 도구가 카드 뉴스 메타로만 사용. 누락해도 무방.

### `cover.type`
- 반드시 `"E1"`. 다른 값 금지.

### `cover.pill`
- 카테고리 라벨. 짧고 명료.
- **권장 라벨**: `NEWS`, `트렌드`, `데이터`, `매장 운영 TIP`, `정책 가이드`, `사장님 사례`, `시즌 리포트`
- 길이 1~6자. 영문은 대문자.

### `cover.main1`, `cover.main2`
- 표지 메인 카피. **공백·구두점 포함 8~14자**.
- main1 → main2가 자연스러운 한 호흡으로 읽혀야 함.
- 강조 `{}` 사용 가능하나 표지에선 절제 (0~1개).

### `interiors[].type`
- `interiorSlot`과 같은 값 (`"E2"` · `"E4"` · `"E5"` · `"E8"`). 세트 안에서 섞지 않습니다.

### `interiors[].main1`, `interiors[].main2`  *(E2·E4·E5)*
- 내지 메인 카피. **공백·구두점 포함 10~16자**.
- 슬라이드당 한 메시지.
- 강조 `{}`는 슬라이드당 1~2개 권장.

### `interiors[].title1` / `title2` / `items`  *(E8)*
- 2-2 체크리스트 세트 참고. 타이틀 6~14자 · 항목 3~5개 · 항목 제목 15자 내외.

### `interiors[]` 배열 길이
- **최소 3장, 최대 6장**.
- 권장 4~5장. (E8은 항목 총 개수에 맞춰 2~4장도 괜찮습니다)

## 4. `{중괄호}` 강조 규칙

도구에서 `{}`로 감싼 텍스트는 **자동으로 포인트 컬러**로 표시됩니다. (도구 UI에서는 같은 스타일이 `##컬러##`로 표기되지만, `{}`도 그대로 동작하니 출력은 `{}`로 통일하세요.)

E8 체크리스트의 `title1`·`title2`·`items[].text`·`items[].desc`에서도 동일하게 동작합니다.

### 강조 대상 (우선순위)
1. **숫자·단위**: `{35.6%}`, `{2.5배}`, `{300만원}`, `{6/15까지}`, `{10,030원}`
2. **핵심 명사구**: `{서울 주요 벚꽃 상권 매출}`, `{잠실}`, `{고유가 피해지원금}`
3. **질문의 답이 될 단어**: `{어떤 업종}`, `{어디가}`, `{얼마나}`

### 강조 금지
- 조사·접속사만: `{이}`, `{의}`, `{그리고}` (X)
- 전체 문장: `{메인 카피 1줄 전체}` (X)
- 슬라이드당 3개 이상

### 강조 예시 (정/오)

**Good** — 숫자 + 명사구 균형
```
"{잠실}은 일식 매출이 전월 대비 {5.4배} 늘었어요"
```

**Good** — 핵심 키워드 한 덩어리
```
"{서울 주요 벚꽃 상권 매출}이 올랐어요!"
```

**Bad** — 강조 4개 (분산)
```
"{잠실}은 {일식}이 {전월 대비} {5.4배} 늘었어요"
```

**Bad** — 조사 강조
```
"잠실{은} 일식 매출이 늘었어요"
```

## 5. 검증 체크리스트 (출력 전 자체 확인)

JSON 출력 직전, 아래 항목을 머릿속으로 한 번 점검:

- [ ] `cover.pill`은 6자 이하?
- [ ] `cover.main1`, `cover.main2`는 각 14자 이하?
- [ ] `interiors`는 3~6개?
- [ ] 각 `interiors[].main1`, `main2`는 16자 이하?
- [ ] (E8) 타이틀 14자 이하 · 슬라이드당 항목 3~5개 · 항목 제목 20자 이하?
- [ ] (E8) 여러 장이면 타이틀이 동일하고 `startNo`는 생략했는지?
- [ ] 슬라이드마다 `{}` 강조 1~2개?
- [ ] 친근체(`~요`, `~까요`)로 끝나고 `~다`/`~한다` 없음?
- [ ] 광고체(`놓치지 마세요`, `지금 바로`) 없음?
- [ ] 이모지 없음?
- [ ] 숫자 데이터가 본문에 노출?
- [ ] 슬라이드 간 흐름이 끊기지 않음?

전부 OK면 출력.

## 7. 사용자 추가 요청 처리

사용자가 후속 요청을 할 수 있습니다:

- **"내지 더 추가해줘"** → 기존 JSON에서 `interiors` 배열에 슬라이드 추가하여 전체 JSON 재출력.
- **"표지 톤 바꿔줘 / 더 후킹 있게"** → `cover` 부분만 재작성. 전체 JSON 재출력.
- **"강조 줄여줘"** → `{}` 개수 줄여서 전체 JSON 재출력.
- **"숫자 더 살려줘"** → 본문에 데이터 더 노출하도록 재작성.

**항상 전체 JSON으로 출력**합니다. 부분 출력 / 차이만 출력 금지.
