# 카드 뉴스 예시 모음 (Few-shot)

실제 페이히어 카드 뉴스의 톤·구조를 학습하기 위한 레퍼런스. 새 카피를 작성할 때 이 예시들의 호흡과 흐름을 모방하세요.

---

## 예시 1 — 벚꽃 상권 매출 분석 (NEWS)

**제목**: 벚꽃 상권 매출, 어디가 얼마나 올랐을까?
**원문 가정**: 페이히어 결제 데이터 분석 — 2024년 벚꽃 시즌(4/3~4/12) 서울 주요 벚꽃 명소 상권의 매출 변동

```json
{
  "title": "벚꽃 상권 매출 분석",
  "source": "https://payhere.in/blog/cherry-blossom-trends/",
  "cover": {
    "type": "E1",
    "pill": "NEWS",
    "main1": "벚꽃 상권 매출,",
    "main2": "어디가 얼마나 올랐을까?"
  },
  "interiorSlot": "E5",
  "interiors": [
    {
      "type": "E5",
      "head": "{서울 벚꽃 상권 매출}이 올랐어요",
      "body": "벚꽃 나들이가 소비로 이어지면서\n주요 명소 상권이 들썩였어요"
    },
    {
      "type": "E5",
      "head": "{잠실}과 {종로}가 가장 크게 뛰었어요",
      "body": "어떤 업종에서 매출이 늘었는지\n하나씩 볼게요"
    },
    {
      "type": "E5",
      "head": "잠실은 일식·주점·양식이 강세",
      "body": "전월 대비 최대 {5.4배}까지 뛰었어요"
    },
    {
      "type": "E5",
      "head": "종로는 선물·기념품이 1위",
      "body": "전월 대비 {61%} 늘었어요"
    },
    {
      "type": "E5",
      "head": "벚꽃이 진 뒤에도 쓸 수 있어요",
      "body": "시즌 상권 데이터를 보고\n우리 매장 메뉴를 조정해 보세요"
    }
  ]
}
```

**해설**:
- 표지: 콤마 호흡 + 의문문. "어디가" "얼마나" 두 가지 궁금증을 묶어 강한 후킹.
- 내지 1: 헤드에 결론, 본문에 맥락. E5는 **헤드가 크게(50px) 먼저 읽히므로 결론을 헤드에** 둡니다.
- 내지 2: 헤드로 전환, 본문 질문으로 다음 슬라이드 유도.
- 내지 3·4: 헤드=지역·업종, 본문=수치. 강조는 수치에만.
- 내지 5: CTA. 광고체 없이 자연스럽게 마무리.

## 예시 2 — 고유가 피해지원금 가이드 (매장 운영 TIP)

**제목**: 고유가 피해지원금 핵심 요약.zip
**원문 가정**: 정부 고유가 피해지원금 정책 안내. 자영업자 대상 신청 자격·금액·기간 정리.

```json
{
  "title": "고유가 피해지원금 가이드",
  "source": "https://payhere.in/blog/oil-price-relief/",
  "cover": {
    "type": "E1",
    "pill": "매장 운영 TIP",
    "main1": "고유가 피해지원금",
    "main2": "핵심 요약.zip"
  },
  "interiors": [
    {
      "type": "E5",
      "head": "{연 매출 3억 이하}가 대상이에요",
      "body": "업종 제한 없이 신청할 수 있어요"
    },
    {
      "type": "E5",
      "head": "최대 {300만원}까지 받아요",
      "body": "신청 기간은 {6월 15일까지}예요"
    },
    {
      "type": "E5",
      "head": "{정부24}에서 온라인으로 신청해요",
      "body": "{관할 시·군·구청} 방문으로도 가능해요"
    },
    {
      "type": "E5",
      "head": "기간 놓치면 끝이에요",
      "body": "신청 준비물 체크리스트는\n페이히어 블로그에 정리해 뒀어요"
    }
  ]
}
```

**해설**:
- 표지: `.zip` 압축 패턴. "핵심 요약"이라는 카피로 정보성 콘텐츠임을 명확히.
- 내지: 매 슬라이드 한 정보(자격 / 금액·기간 / 신청 방법 / CTA).
- 강조: 숫자(`{300만원}`, `{6월 15일까지}`)와 지명(`{정부24}`)에 집중.
- 마지막: 가벼운 후킹 + CTA. "끝!"의 느낌표는 절제된 1개.

## 예시 3 — 외국인 결제 트렌드 (트렌드)

**제목**: 외국인이 한국에서 가장 많이 결제한 업종은?

```json
{
  "title": "2024 외국인 결제 트렌드",
  "source": "https://payhere.in/blog/foreign-payment-2024/",
  "cover": {
    "type": "E1",
    "pill": "트렌드",
    "main1": "외국인이 한국에서",
    "main2": "가장 많이 결제한 업종은?"
  },
  "interiors": [
    {
      "type": "E5",
      "head": "{어떤 업종}이 1위였을까요?",
      "body": "2024년 외국인 결제 데이터를\n업종별로 살펴봤어요"
    },
    {
      "type": "E5",
      "head": "1위는 {일식}이었어요",
      "body": "전년 대비 {35.6%} 늘었어요"
    },
    {
      "type": "E5",
      "head": "2·3위는 카페와 기념품숍",
      "body": "관광 동선을 따라가는 소비 패턴이에요"
    },
    {
      "type": "E5",
      "head": "K-콘텐츠가 이끈 변화예요",
      "body": "우리 매장 메뉴에도\n반영해 볼 수 있을까요?"
    }
  ]
}
```

**해설**:
- 표지: 단순 질문형. "한국에서 / 가장 많이 / 결제한"으로 호흡이 자연스러움.
- 내지 1: 질문 강조로 다음 슬라이드 시선 유도.
- 내지 2·3: 1위 → 2·3위 데이터 노출. 비교 흐름.
- 내지 4: 시사점. "K-콘텐츠"라는 트렌드 키워드 + 사장님 시점 CTA.

## 예시 4 — 최저임금 인상 (정책 가이드)

**제목**: 2025년 최저임금, 우리 매장에 얼마 영향?

```json
{
  "title": "2025 최저임금 영향 분석",
  "source": "https://payhere.in/blog/min-wage-2025/",
  "cover": {
    "type": "E1",
    "pill": "정책 가이드",
    "main1": "2025년 최저임금,",
    "main2": "우리 매장에 얼마 영향?"
  },
  "interiors": [
    {
      "type": "E5",
      "head": "최저임금 {10,030원}이 됐어요",
      "body": "2025년부터 적용되는 시간당 금액이에요"
    },
    {
      "type": "E5",
      "head": "월급으로 {209만 6,270원}",
      "body": "전년 대비 {1.7%} 오른 금액이에요"
    },
    {
      "type": "E5",
      "head": "주휴수당까지 더하면 더 올라가요",
      "body": "사실상 {시급 12,036원} 수준이에요"
    },
    {
      "type": "E5",
      "head": "직원 1명당 월 {3.5만원} 늘어요",
      "body": "인건비 계획을 미리 세워두면\n부담이 덜해요"
    },
    {
      "type": "E5",
      "head": "정확한 계산이 필요하다면",
      "body": "{페이히어 블로그}에 시뮬레이션이 있어요"
    }
  ]
}
```

**해설**:
- 표지: 사장님 직접 질문형 ("우리 매장에 얼마 영향?"). 친근하고 즉시 관련성.
- 내지: 숫자가 거의 모든 슬라이드에 등장. 정책 가이드의 핵심.
- 강조: 모든 슬라이드의 `{}`가 **숫자/금액** — 일관된 강조 패턴.
- 마지막: 페이히어 블로그로 자연스러운 연결.

---

## 응용 — 좋은 카드 뉴스의 공통점

1. **표지가 짧고 강하다** — 한 줄 14자 이하. 질문 또는 압축.
2. **내지마다 숫자가 있다** — 데이터 카드 뉴스의 본질.
3. **강조는 절제** — 슬라이드당 1~2개 `{}`.
4. **흐름이 끊기지 않는다** — 슬라이드 → 슬라이드가 "그래서?"의 답.
5. **마지막이 가볍다** — 광고체 없이 자연스러운 CTA 또는 시사점.

새 카피를 쓸 때 이 다섯 가지를 체크하세요.
