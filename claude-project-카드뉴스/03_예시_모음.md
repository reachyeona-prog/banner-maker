# 카드 뉴스 예시 모음 (Few-shot)

실제 페이히어 카드 뉴스의 톤·구조를 학습하기 위한 레퍼런스. 새 카피를 작성할 때 이 예시들의 호흡과 흐름을 모방하세요.

---

## 예시 1 — 외국인 카드 소비 2조 돌파 (사장님 뉴스) · 실제 발행 카드

**제목**: 외국인 카드 소비 2조 돌파, 우리 매장도 늘리는 방법
**원문 가정**: 한국은행 외국인 카드 소비 통계 + 페이히어 해외 결제 서비스 소개

```json
{
  "title": "외국인 카드 소비 2조 돌파",
  "source": "https://payhere.in/blog/foreign-card-2025/",
  "cover": {
    "type": "E1",
    "pill": "사장님 뉴스",
    "main1": "외국인 카드 소비 2조 돌파,",
    "main2": "우리 매장도 늘리는 방법",
    "bubble": ["도소매 매장이라면", "OOOO은 필수👀"]
  },
  "interiorSlot": "E5",
  "interiors": [
    {
      "type": "E5",
      "head": "사상 처음으로 2조 원 돌파",
      "body": [
        "올해 5월, 외국인 관광객의 국내 카드 소비가",
        "{2조 1222억 원을 기록}했어요",
        "지난해 같은 달보다 {67.1% 증가}했는데요",
        "",
        "업종별로 살펴보면요 →"
      ],
      "note": "출처: 한국은행, 2025.06.30"
    },
    {
      "type": "E5",
      "head": "일반 상권의 외국인 결제 증가",
      "body": [
        "백화점(89.2%), 면세점(87.6%)은 물론",
        "쇼핑업(77.8%), 식음료업(64.9%) 등",
        "{일반 상권에서 외국인 결제가 증가}하고 있어요",
        "K-일상을 체험하려는 {데일리케이션 영향}인데요",
        "",
        "그런데, 이 돈이 몰리는 매장은 따로 있어요 →"
      ]
    },
    {
      "type": "E5",
      "head": "환급부터 해외 결제까지 한 번에",
      "body": [
        "{가입비, 사용료, 수수료 모두 0원}",
        "방법도 쉬워요, 카드 단말기로 {여권을 스캔}하고",
        "알리페이, 위챗페이 등으로 결제하면 완료!",
        "",
        "지금 프로필 링크에서 {무료 신청}해 보세요"
      ],
      "bubble": "여권을 자동으로\n인식해요"
    }
  ]
}
```

**해설**:
- 표지: 숫자(2조) + 사장님 이득("우리 매장도")을 한 호흡에. main1 끝 쉼표로 main2를 받음.
- 표지 말풍선: 본문과 다른 목소리. 구어체 + 이모지 + `OOOO`로 궁금증 유발.
- 내지 1: 헤드=결론(2조 돌파), 본문=수치 근거. **빈 줄 뒤 유도 문구(`→`)**로 다음 장 연결.
- 내지 2: 업종별 숫자를 괄호로 압축해 두 줄에 몰고, 결론 구절을 통째로 강조.
- 내지 3: 마지막 장은 유도 대신 CTA. 광고체 없이 "신청해 보세요".
- `note`: 통계를 인용한 장에만 출처. 페이히어 서비스 설명 장에는 없음.

## 예시 2 — 고유가 피해지원금 가이드 (매장 운영 TIP)

**제목**: 고유가 피해지원금 핵심 요약.zip
**원문 가정**: 정부 고유가 피해지원금 정책 안내. 자영업자 대상 신청 자격·금액·기간 정리.

```json
        "정부가 피해지원금을 새로 마련했는데요",

        "",
        "프로필 링크에서 확인해 보세요"
```

- 표지: `.zip` 압축 패턴. "핵심 요약"이라는 카피로 정보성 콘텐츠임을 명확히.
- 내지: 매 슬라이드 한 정보(자격 / 금액·기간 / 신청 방법 / CTA).
- 강조: 숫자(`{300만원}`, `{6월 15일까지}`)와 지명(`{정부24}`)에 집중.
- 마지막: 가벼운 후킹 + CTA. "끝!"의 느낌표는 절제된 1개.

## 예시 5 — CCTV 설치 체크리스트 (카드형 E8) · 실제 발행 카드

**제목**: 매장 CCTV, 잘못 달면 과태료 5천만 원
**형식**: 항목 나열형 → `interiorSlot: "E8"`

```json
{
  "title": "CCTV 설치 체크리스트",
  "source": "",
  "cover": {
    "type": "E1",
    "pill": "매장 운영 TIP",
    "main1": "매장 CCTV, 잘못 달면",
    "main2": "과태료 5천만 원"
  },
  "interiorSlot": "E8",
  "interiors": [
    {
      "type": "E8",
      "title1": "CCTV 체크 리스트",
      "title2": "설치할 때",
      "items": [
        {
          "text": "CCTV 안내판 부착하셨나요?",
          "desc": ["((목적·촬영 범위·보관 기간·관리 책임자 4가지를))", "안내하지 않으면, 과태료 부과 대상이 될 수 있어요"]
        },
        {
          "text": "공용 공간만 촬영되고 있나요?",
          "desc": ["((화장실·탈의실 등 사생활 침해가 우려되는 곳을))", "촬영하면, 최대 5천만 원 과태료가 부과될 수 있어요"]
        },
        {
          "text": "매장 외부는 안 찍히고 있나요?",
          "desc": ["출입구 CCTV가 ((인접 도로나 건물까지 촬영))하면", "불필요한 민원의 대상이 될 수 있어요"]
        },
        {
          "text": "특정 고객·직원이 과도하게 확대 촬영되고 있진 않나요?",
          "desc": ["사고 확인에 ((필요한 수준을 넘어선 화질·구도는))", "개인정보 과잉 수집으로 해석될 수 있어요"]
        },
        {
          "text": "직원 근무 공간 촬영, 사전 고지 하셨나요?",
          "desc": ["카운터·주방 등 직원 근무 공간은 사전 고지 없이 촬영하면", "((감시로 해석돼 노무 분쟁))으로 이어질 수 있어요"]
        }
      ],
      "note": "출처: 개인정보보호위원회"
    }
  ]
}
```

**해설**:
- 항목 5개가 한 장. 모든 항목이 `~하셨나요? / ~있나요?` 확인형으로 통일돼 리듬이 생김.
- `desc`는 2줄 고정 패턴: **1줄=조건(볼드), 2줄=결과("~될 수 있어요")**. 사장님이 위험을 바로 체감함.
- 강조는 `{}`(포인트 컬러)가 아니라 `((볼드))`. 흰 카드 위 검정 글씨라 볼드가 더 또렷해요.
- 항목 제목이 길어도(26~30자) 도구가 자동으로 줄여 담습니다.

## 예시 6 — 장마철 사장님 체크리스트 (배경형 E8) · 실제 발행 카드

```json
  "interiorSlot": "E8",
  "interiors": [
    {
      "type": "E8",
      "title1": "🌂 2026 장마철",
      "title2": "사장님 체크리스트",
      "titleStyle": "point",
      "card": false,
      "numbered": false,
      "items": [
        { "text": "간판, 천막, 어닝 등 ==외부 시설 고정 상태 점검==" },

        { "text": "==입구에 미끄럼 방지 매트 배치==", "desc": "빗물에 젖은 바닥 낙상 사고 예방" },

```

**해설**:
- 배경형은 항목을 **7개까지** 담아 "쭉 훑는" 리스트 느낌. 카드형(5개)보다 가볍습니다.
- 항목이 질문형이 아니라 **명사형 점검 항목**(`~점검`, `~배치`, `~비치`). 확인형과 섞지 말고 한 세트 안에서 통일하세요.
- 강조는 `==형광펜==`. 항목의 **핵심 동작**만 칠합니다.
- `desc`는 부연이 꼭 필요한 항목에만. 전부 붙이면 답답해져요.
- 타이틀 이모지(`🌂`)는 시즌물에서 자주 씁니다.
