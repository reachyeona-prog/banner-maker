# 카드 뉴스 카피라이터 — Claude 프로젝트 셋업

페이히어 인스타그램 카드 뉴스(1080×1440) 카피를 만드는 Claude 프로젝트 지침입니다. 기사·블로그 **본문 텍스트**를 던지면 슬라이드별 카피·이미지 프롬프트·캡션과 배너 메이커용 JSON을 돌려줍니다.

## 파일

| 파일 | 용도 |
| --- | --- |
| **[인스타그램_지침_v2.2.md](인스타그램_지침_v2.2.md)** | **운영 지침 전문.** 프로젝트 Instructions에 통째로 붙여넣기 |
| `README.md` | 이 문서 |

**파일은 이거 하나입니다.** Knowledge에 따로 올릴 파일 없어요 — 톤·구조·예시·JSON 스키마가 전부 지침 안에 들어 있습니다.

## 셋업

1. [claude.ai/projects](https://claude.ai/projects) → 프로젝트 만들기
2. **Instructions**에 `인스타그램_지침_v2.2.md` 전문을 복사·붙여넣기 (파일 첨부 X, 본문 텍스트로)
3. Knowledge 영역은 비워둡니다. 예전에 올려둔 `00`~`04` 파일이 있으면 **삭제** — 지금 지침과 필드가 어긋납니다
4. 모델은 Sonnet 4.6 또는 Opus 4.7 권장

## 사용

```
아래 글로 카드 뉴스 만들어줘.

[본문 전체 …]
```

항목 나열형(점검·준비물·단계)이면 `체크리스트로 만들어줘`를 덧붙이세요 → 한 장에 5~7개 항목이 들어가는 체크리스트 카드로 뽑아줍니다.

출력 마지막의 JSON을 배너 메이커(`index.html`)의 "Claude 카피 한 번에 채우기"에 붙여넣으면 표지·내지가 자동으로 채워집니다.

## 도구와 맞물리는 지점

지침 9번의 JSON 형식은 배너 메이커의 임포터(`applyCardNewsJSON`)와 1:1로 맞춰져 있습니다. **한쪽을 바꾸면 다른 쪽도 같이 고쳐야 해요.**

| 지침 필드 | 도구 |
| --- | --- |
| `interiorSlot: "E5"` / `"E8"` | 내지 슬롯 (설명형 / 체크리스트 카드) |
| `main1` + `sub1`~`sub9` | E5 헤드 + 본문 (빈 문자열 = 빈 줄) |
| `title1`/`title2`/`items` | E8 체크리스트 |
| `note` | 우측 하단 출처 표기 |
| `bubble` | 말풍선 문구 (위치·색은 도구에서) |

## 업데이트

지침은 **이 파일 하나만 고칩니다.** 버전이 올라가면 파일명 뒤 버전을 바꾸고, 프로젝트 Instructions를 통째로 교체하세요. 파일을 나눠두면 어느 게 최신인지 헷갈려서 규칙이 어긋납니다 (v2.1 시절 실제로 발생).

글자 수·레이아웃 규칙을 바꿀 땐 `카드 뉴스 샘플/`의 실제 발행 카드를 열어 실측값과 맞는지 먼저 확인하세요.
